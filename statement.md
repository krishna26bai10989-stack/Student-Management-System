# Student Management System

## 1. Problem Statement

Managing student information manually can be time-consuming and may lead to errors, duplicate records, and difficulty in searching or updating student details.

The Student Management System is a Python-based application designed to manage student records in a simple and organized way. It allows users to add, view, search, update, and delete student information.

The system stores student data using a JSON file so that records remain available even after the program is closed.

---

## 2. Project Scope

The scope of this project includes managing basic student information such as:

- Student Name
- Roll Number
- Course

The system provides CRUD operations:

- Create student records
- Read/view student records
- Update student records
- Delete student records

It also provides student search and basic reports.

The project is designed as a command-line application and can be further extended into a graphical or web-based application.

---

## 3. Target Users

The target users of this system are:

- Students learning Python programming
- Teachers and faculty members
- Small educational institutions
- Beginners learning software development
- Users who need a simple student record management system

---

## 4. High-Level Features

### Student Management
- Add new student
- View all students
- Search student by roll number
- Update student details
- Delete student records

### Data Storage
- Store student records in a JSON file
- Load saved records when the application starts
- Save changes automatically

### Validation and Error Handling
- Prevent empty student details
- Prevent duplicate roll numbers
- Handle missing student records
- Handle invalid or corrupted JSON data

### Student Reports
- Display total number of students
- Display students according to their course

### Testing
- Automated testing using pytest
- Tests for adding, searching, and deleting students

---

## 5. Project Objective

The main objective of this project is to develop a simple, modular, and reliable Student Management System while applying Python programming concepts such as:

- Functions
- Classes and Objects
- Lists
- Loops
- Conditional Statements
- File Handling
- JSON Data Storage
- Exception Handling
- Modular Programming
- Automated Testing
